## 1. Limpieza de la base de datos

De ser pertinente, limpiar y preparar la base de datos de MOLEC del INEGI considerando los siguientes criterios:

- **Periodo de estudio:** 1993–2089.
- **Estados:** Michoacán, Guerrero y Tamaulipas.
- **Validación:** revisar valores faltantes, registros duplicados y consistencia de las variables.

## 2. Ejecución del análisis

Una vez que la base de datos esté limpia, ejecutar el archivo `do_homework.py` desde la terminal:


## 3. Objetivo del proyecto

Analizar los hábitos de lectura en México mediante los datos de MOLEC del INEGI, identificando patrones y tendencias en Michoacán, Guerrero y Tamaulipas durante el periodo de estudio.
